- With the window maximised or wider than 1600 pixels, the Setup page uses the extra width. In the
  List view each category row shows a chip per module that switches it on or off without opening
  the category (off modules are struck through, heavy ones carry an amber dot), with Runs on and a
  Heavy badge for the category. In the Rail view the chosen category's modules are cards with
  their options edited in place: options changed from their defaults are highlighted with the
  default and a Reset link, the rail marks categories with changed options, and above the list a
  count of changed options sits beside Reset all options and an Only show changed filter. The
  Profile box reads "(current selection, modified)" while options are changed. The default window
  size keeps the layout it had.
