### Features

* **Data access:** DataAccess.csv has a new last column, Artefact, naming the artefact each row came from (LNK (Recent), LNK (Office Recent), Jump lists, ShellBags, RecentDocs, OpenSavePidlMRU, Office File MRU, Security 5140, Security 5145, Security 4663, recently-used.xbel or .viminfo), so a row can be checked against its source. The case report's data access section counts each account's rows by artefact as well as by activity. The lake's DataAccess.csv has the same column.
