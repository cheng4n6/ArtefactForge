### Features

* **Evidence lake:** the timeline now also holds Amcache (with SHA1), ShimCache, BAM, autoruns, LNK files, jump lists, ShellBags, the Recycle Bin, SRUM network and application use, Hayabusa and Chainsaw detections, and the Linux auth, journal, syslog, audit, web, login and bodyfile output, so a hash, a program or an address can be followed across hosts. New `detections` and `network_usage` views list rule hits and the bytes each program sent. Linux log lines with only the host's local time are converted to UTC with the host's time zone, each at its own date's offset, and marked as converted; rows whose time cannot be read, or with no usable time zone, stay in their raw table and are counted in lake.log rather than dropped. ArtefactForge's own results (ransomware, data access, IP history, remote access, IOC hits) are loaded too.
