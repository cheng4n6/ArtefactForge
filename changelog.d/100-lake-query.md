### Features

* **Evidence lake:** a Query lake button on the Analysis overview opens the case's lake read-only in the DuckDB CLI, DuckDB's web UI or DBeaver. It checks the program is installed and new enough to open the lake first, says what to install if not, and lets you point at the program if it is somewhere else. The web UI needs its ui extension, which ArtefactForge offers to install (a download from DuckDB), and internet access while it is open.
